# Ponto Estúdio 2.0

Estúdio musical para criação de pontinhos, com playlist de até 128 compassos, piano roll, instrumentos personalizados, clipes de áudio e exportação WAV.

## Execução

O aplicativo é estático e roda no navegador. Após adicionar os arquivos da distribuição, abra `index.html`. O banco de sons é dividido em seis scripts, carregados em ordem pelo HTML. Mantenha todos os arquivos na mesma pasta.

Os arquivos do aplicativo ainda precisam ser enviados a esta pasta.
